## 📘 Descripción general del sistema
Este proyecto corresponde a mi tarea sumativa 2 correspondiente a la semana 3 del actual bimestre, Trata de un sistema de gestión para una agencia de Turismo llamada Llanquihue Tour, donde planea facilitar su funcionamiento y dar orden y estructuramiento mediante un diseño de modelo de clases que representa a las personas vinculadas a la organizacion considerando atributos, relaciones y principios de encapsulamiento, para establecer una base sólida sobre la cual construir el sistema completo en fases futuras.
